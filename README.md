# Yunlei Shen — Portfolio

Personal portfolio of Yunlei Shen, product designer: four case studies (The End of the Paper Trail, A CRM Worth Navigating, Four Roles One System, The Two-Minute Deal) plus an About page.

## Tech stack
Pure static HTML, CSS, and JavaScript — no build step, no dependencies. Interactive case-study walkthroughs are self-contained HTML pages embedded via iframes.

## Responsive
One codebase, fully responsive: fluid flex/grid layouts with CSS media queries adapt from mobile (320px+) through tablet (768px+) to desktop (1024px+), with a mobile navigation menu.

## Deploy to GitHub Pages
Settings → Pages → Source: deploy from branch `main`, folder `/ (root)`.
